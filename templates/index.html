async-media-fetcher

Flask + asyncio demo — fetch GIFs or heavyweight videos concurrently, stream results as they finish.

Pick what to download, how many items and how aggressively to parallelize, then press Start. The server fetches every item with asyncio and pushes each result to this page as soon as it is ready. The five run modes mirror the command-line demo this project came from — same patterns, same metrics.

How the run modes map to the CLI demo
CLI demoThis page
run_sync_demo — blocking loopmode sync → /api/stream?mode=sync
run_async_gather_demo — asyncio.gathermode gather → /api/fetch
run_async_streaming_demo — as_completedmode stream → /api/stream?mode=stream (SSE)
run_timeout_demo — asyncio.wait + cancelmode timeout → /api/stream?mode=timeout
print_comparisonmode compare → /api/compare

In sim mode the "planned wait" of each item plays the role of the fixed delay from the CLI demo. The heavy video (30 MB / 6.5 s planned) exists specifically so the timeout mode has something to cancel.

Sources: Giphy CDN, test-videos.co.uk (CC), MDN sample (CC0). In sim mode fixtures are generated locally with Pillow/ffmpeg. Downloaded bytes are held in memory for 20 minutes and served from /media/<req_id>/<item_id> with Range support, so videos can be scrubbed in place.
